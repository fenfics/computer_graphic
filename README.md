# Computer Graphics

This repository contains laboratory exercises, workshops, and course projects completed during the Computer Graphics course. The projects focus on web-based 3D graphics, rendering techniques, GPU programming concepts, and interactive graphics applications.

## Repository Structure

```
computer_graphic
├── Christmas_proj
├── GPU_Mesh
├── PBR-AHM
├── Portfolio_Project
├── Trip_Bangsean
├── gpuMeshFile
├── gputransformation
└── Assets
```

## Topics Covered

- Computer Graphics Fundamentals
- GPU Rendering
- Mesh and Geometry
- 3D Model Loading
- Transformations
- Lighting and Shading
- Physically Based Rendering (PBR)
- Environment Mapping
- Texture Mapping
- Interactive Web Graphics

## Projects

| Project | Description |
|---------|-------------|
| Portfolio_Project | Interactive personal portfolio with 3D graphics |
| Christmas_proj | Christmas-themed interactive graphics project |
| Trip_Bangsean | Interactive travel-themed graphics application |
| GPU_Mesh | Mesh rendering and GPU graphics exercises |
| PBR-AHM | Physically Based Rendering (PBR) demonstration |
| gpuMeshFile | Loading and rendering external mesh models |
| gputransformation | Transformation and matrix operation examples |
